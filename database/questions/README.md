# أسئلة لعبة الفريقين

كل ملف `.txt` في هذا المجلد (مثل `batch1-1.txt`) يُستورد تلقائياً عند كل نشر (`db:seed`)،
أو يدوياً عبر:

```bash
php artisan questions:import --check   # فحص الملفات فقط بدون أي كتابة
php artisan questions:import           # فحص ثم استيراد
```

## شكل الملف

```
# أي سطر يبدأ بـ # هو تعليق
@category football
200|من فاز بكأس العالم 2010؟|إسبانيا|هولندا|ألمانيا|الأرجنتين
400|...|...|...|...|...
600|...|...|...|...|...

@category history
200|...
```

- `@category <slug>`: الفئة التي تتبعها كل الأسطر التالية حتى `@category` التالية.
- كل سؤال في سطر واحد، و 6 حقول مفصولة بـ `|`:
  `النقاط|السؤال|الإجابة الصحيحة|خيار خاطئ|خيار خاطئ|خيار خاطئ`
- **النقاط**: `200` سهل، `400` متوسط، `600` صعب.
- **الإجابة الصحيحة هي الخيار الأول دائماً**، وترتيب الخيارات يُخلط تلقائياً عند الاستيراد.

## قواعد اللعبة

كل لعبة فيها **6 فئات**، وكل فئة **6 أسئلة**: سؤالان بـ 200، وسؤالان بـ 400، وسؤالان بـ 600.
لذلك لا تظهر الفئة في اختيار الفئات إلا إذا كان فيها سؤالان على الأقل من كل مستوى،
وكلما زادت الأسئلة قل التكرار بين الألعاب.

## ملاحظات

- إذا وُجد أي خطأ في أي ملف (نقاط غير صحيحة، عدد حقول خاطئ، فئة غير موجودة، سؤال مكرر…)
  لا يُستورد شيء، ويظهر رقم السطر وسبب الخطأ.
- حذف سؤال من الملف يُوقفه في اللعبة عند الاستيراد التالي.
- تعديل نص السؤال يُعامل كسؤال جديد، وتعديل الإجابات يحدّث السؤال نفسه.
- الأسئلة المضافة من لوحة التحكم أو من اقتراحات المستخدمين لا تتأثر بهذه الملفات.
